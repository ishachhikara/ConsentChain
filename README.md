# ConsentChain 🔐
### Transparent. Secure. User-Controlled Data Sharing.

ConsentChain is a consent management prototype designed to give users greater visibility and control over how their data is shared. It provides an interface to create profiles, grant permissions, revoke access, and manage consent-related information.

🔗 **Live Demo:** https://ishachhikara.github.io/ConsentChain/

## ✨ Key Features

- **Profile Creation** — Create a new profile to get started.
- **Consent Management** — Grant permissions for data access.
- **Access Revocation** — Revoke previously granted permissions.
- **User-Friendly Interface** — Manage consent through a simple dashboard.
- **Demo Experience** — Explore the interface and its workflows.

## 🎯 Problem Statement

Data sharing often lacks transparency and clear user control. People may not know what information they have permitted others to access or how to withdraw that permission.

ConsentChain explores a more transparent approach to consent management, where permissions can be reviewed and controlled through a single interface.

## 💡 Our Approach

ConsentChain focuses on three core principles:

1. **Transparency** — Make consent information easier to understand.
2. **Control** — Allow users to grant and revoke permissions.
3. **Accountability** — Support clearer visibility into consent-related actions.
